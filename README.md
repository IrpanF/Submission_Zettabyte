💡 Konsep Dasar JavaScriptJavaScript dirancang untuk berjalan langsung di dalam browser (sisi klien), namun kini juga bisa digunakan di sisi server menggunakan runtime seperti Node.js.HTML: Menentukan struktur halaman (misal: membuat tombol).CSS: Mengatur tampilan dan gaya halaman (misal: memberi warna pada tombol).JavaScript: Mengontrol perilaku halaman (misal: apa yang terjadi saat tombol diklik).
